# Codex Mobile · Личная копия 0.6.9

Снимок личного Android-клиента `local.avr.codex.copy` на базе [основного Codex Mobile](https://github.com/lolkofka/codex-mobile/tree/main). Модель работает онлайн, команды и файлы — в собственном root-окружении на телефоне или по SSH на выбранном сервере.

**Неофициальный проект.** Не является приложением ChatGPT от OpenAI и не разделяет его обычную историю чатов.

[Предыдущий подписанный релиз 0.6.6](https://github.com/lolkofka/codex-mobile/releases/tag/v0.6.6-copy) · [Установка копии](docs/INSTALL.md) · [Сборка](docs/BUILD.md) · [Настройки и дизайн](docs/UI_SETTINGS.md)

## Изменения

- Смешанные подписки добавляют совместимые серверы и явно показывают, какие неподдерживаемые протоколы пропущены.
- Чаты поднимаются только после сообщения или нового ответа. Открытие и просмотр не меняют порядок. Порядок закрепов сохраняется, активность хранится между перезапусками отдельно для телефона и ПК.
- Новый общий тёмный стиль с мятными акцентами, карточками, крупными действиями и навигацией «Назад».
- Настройки по разделам: аккаунт, подключение, Xray, рабочие серверы, доступ к телефону, уведомления и обслуживание.
- Ссылки на локальные файлы: «Отправить…» через системный выбор приложений (включая Telegram) либо «Открыть». Получатель читает сам файл через временный read-only URI.
- Встроенный Xray 26.11.9: подписки, выбор хоста, XHTTP `extra`, XMUX, padding и отдельный канал загрузки. При включённом Xray нет автоматического прямого обхода или переключения хоста.
- Именованные SSH-серверы, шифрование профилей Android Keystore, закрепление ключа сервера. При наличии SSH-ключа отдельный пароль используется для root через `su`.
- Синие/жёлтые индикаторы выполняющихся и ожидающих подтверждения чатов, картинка в уведомлениях.
- Отдельный переключатель фоновых приложений и видимый ограниченный сеанс HTTPS с временным сертификатом и очисткой после завершения/сбоя.

## Границы сборки

Это отдельная ветка личной копии для существующего окружения AVR, с его путями и UID. Основная ветка `main` сохраняет исходный пакет. APK не содержит аккаунта, подписок, паролей, SSH-ключей, сертификатов перехвата или приватного ключа подписи. Повторная сборка с новым signing key не заменит установленный APK с другим ключом.

Xray публикуется как закреплённая зависимость: сборщик скачивает официальный ARM64 архив и проверяет SHA-256 архива и бинарника. Сам бинарник и SDK не хранятся в Git. Сборка не запускает root helpers и не устанавливает сертификаты на телефон.

## Проверки

На синтетических данных выполнены 54 проверки интерфейса и 11 проверок передачи файла между разными UID приложений; проверены меню отправки и изоляция read-only URI. Xray/XHTTP, SSH и жизненный цикл временного HTTPS проверялись отдельно при разработке. Исходники проверок и сборки находятся в `tests/`, `tools/` и `phone-tools/`.
