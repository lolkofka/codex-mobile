# Codex Mobile

Личный Android-клиент для официального движка [OpenAI Codex](https://github.com/openai/codex). Модель работает онлайн, а команды, файлы и доступные контейнеры — на телефоне. Вход выполняется через свой аккаунт ChatGPT на официальной странице OpenAI.

**Неофициальный проект.** Он не связан с OpenAI и не является официальным приложением ChatGPT для Android. Его чаты хранятся отдельно от обычных чатов ChatGPT.

## Возможности

- Вход через аккаунт ChatGPT, включая вход по коду устройства.
- Выбор модели из каталога движка и поддерживаемой глубины размышлений.
- Постепенный вывод ответа, доступные сводки размышлений и этапы выполнения инструментов.
- Чаты: история, поиск, продолжение, переименование, архивирование и удаление.
- Очередь сообщений и «Уточнить сейчас» для уже выполняемой задачи; отдельная кнопка остановки.
- Фото из системной галереи, буфера обмена, поддерживаемой клавиатуры и меню «Поделиться». До шести изображений за сообщение.
- Встроенная генерация изображений Codex и показ результата в чате, когда инструмент доступен аккаунту и модели.
- Кликабельные веб-ссылки и ссылки на локальные файлы; просмотр каталога и открытие копии файла через Android.
- Штатные уведомления о завершении/ошибке задачи и foreground-уведомление с действием остановки.
- Системная диктовка, распознавание речи и озвучивание ответа.
- Команды с root и работа с уже настроенным Docker.
- Прототип подключения к ПК по SSH с закреплённым ключом компьютера.

## Требования

- Android 10 / API 29 или новее, ARM64; основная проверенная конфигурация — Android 16.
- Рабочий root с `su` и разрешение для приложения. Приложение не получает root самостоятельно.
- Интернет и аккаунт с доступом к Codex. Доступность моделей, генерации изображений и лимиты определяются аккаунтом и сервисом.
- Отдельно подготовленный runtime Codex **0.165.0**. APK содержит интерфейс, а не ARM64-движок: см. [установку runtime](docs/INSTALL.md).

Docker необязателен. Для него нужны уже установленный движок и подходящее ядро; приложение не собирает ядро и не настраивает Docker.

## Быстрый старт

1. Скачайте APK из [Releases](https://github.com/lolkofka/codex-mobile/releases), установите его и подготовьте runtime по [инструкции](docs/INSTALL.md).
2. При первом запуске разрешите root для Codex Mobile и уведомления Android.
3. Откройте меню истории → аккаунт → вход через браузер или по коду. Войдите на официальном сайте OpenAI и вернитесь в приложение.
4. Выберите модель. Для фото нажмите **«+»**; во время ответа выберите **«В очередь»** или **«Уточнить сейчас»**.

Обновление APK с той же подписью выполняется поверх приложения и сохраняет его данные. Самостоятельная сборка по умолчанию получает отдельную локальную подпись — см. [правила обновления](docs/BUILD.md#подпись-и-обновления).

## Что проверено в 0.6.1

Для 0.6.1 на ARM64-телефоне проверены настоящее обновление токена ChatGPT и HTTPS-запрос из root-движка через новый мост. Пройдены 11 групп native-проверок: вход, очередь, уточнения, восстановление, модели, фото и уведомления. На компьютере проходят 20 проверок интерфейса и 32 проверки входа/сетевого моста с синтетическими данными. Реальные генерация изображения и команды Docker отдельно проверялись в 0.6.0.

Основное устройство разработки: Lenovo Legion Y70 с портом прошивки Motorola и Android 16. Работа на каждом другом устройстве не гарантируется. Импорт через конкретную галерею/клавиатуру и выбор приложения для открытия файлов могут зависеть от прошивки.

## Ограничения и доступ к устройству

Текущий профиль использует root и `danger-full-access` с политикой `on-request`. **Это не изолированная песочница; подтверждение не запрашивается перед каждой командой.** Не поручайте агенту операции, последствия которых не готовы принять. Изменение загрузчика, прошивка и сброс телефона не являются частью установки клиента.

Сводки размышлений показываются только в том объёме, который отдаёт движок. Скрытые внутренние рассуждения не раскрываются.

Режим ПК — SSH-прототип: нужен доступный адрес компьютера или собственная VPN/mesh-сеть. Здесь нет облачного relay «из любой точки», автоматической настройки Windows SSH или подхвата активного чата настольного приложения. Файловые ссылки в этом режиме относятся к ПК; интерфейс не предоставляет универсальный удалённый файловый менеджер. Подробнее: [архитектура](docs/ARCHITECTURE.md).

## Исходники и личные данные

В репозитории опубликованы исходники интерфейса, шаблоны runtime, инструменты сборки, тесты и документация. Авторизация, чаты, журналы телефона, SSH-профили/ключи, VPN-подписки, ключ подписи APK и приватный runtime сюда не включены. APK также не содержит готового аккаунта или подключения VPN.

Перед публикацией исходники и распакованное содержимое APK проверены сканером секретов и дополнительными проверками. Это описывает проверку данного релиза, а не гарантию для произвольных будущих изменений. [Подробнее о хранении данных и сообщениях об уязвимостях](SECURITY.md).
