# Участие

Изменения интерфейса и Android-кода находятся в `android/`. Шаблоны runtime — в `runtime/`, инструменты сборки и тесты — в соответствующих каталогах.

Перед pull request:

1. Запустите `python tools/check_project.py` и соберите APK по [инструкции](docs/BUILD.md).
2. Для изменений интерфейса выполните headless-тесты; для протокола, файлов и Android API — подходящие native-тесты на тестовом устройстве.
3. Укажите проверенную версию Android и границы проверки. Не называйте синтетический тест проверкой реального аккаунта или сетевой генерации.
4. Проверьте diff на учётные данные, приватные адреса, логи и пользовательские файлы. Не добавляйте keystore, `home/auth.json`, SSH-профили или собственный runtime.

Поддерживайте сборку без личных абсолютных путей. Изменение ядра/загрузчика и банковских приложений не относится к этому клиенту.
