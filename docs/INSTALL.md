# Установка

## 1. Проверьте требования

Нужен Android ARM64 с рабочим `su`, Android API 29+ и интернетом. Установщик не разблокирует загрузчик, не прошивает разделы и не устанавливает root, ядро или Docker.

На компьютере нужны Python 3.10+ и `adb` из [Android Platform Tools](https://developer.android.com/tools/releases/platform-tools). Включите отладку и подтвердите доступ компьютеру на экране телефона.

```console
adb devices
adb -s SERIAL shell uname -m
adb -s SERIAL shell su -c "id -u"
```

Замените `SERIAL` своим ADB-идентификатором. Ожидаются `aarch64` и `0`; запрос root для отладки подтвердите на телефоне. Для беспроводной отладки вместо идентификатора можно указать уже сопряжённый адрес `IP:PORT`.

## 2. Установите APK

Скачайте APK и `SHA256SUMS` из [релиза 0.6.0](https://github.com/lolkofka/codex-mobile/releases/tag/v0.6.0). SHA-256 файла должен совпадать с опубликованным значением.

```console
adb -s SERIAL install -r Codex-Mobile-AVR-0.6.0.apk
```

`-r` обновляет приложение с совпадающей подписью, сохраняя его данные. При несовпадении подписи Android отклонит обновление. Не удаляйте установленное приложение ради замены подписи, если хотите сохранить его данные.

## 3. Подготовьте runtime

В каталоге клона репозитория выполните:

```console
python tools/install_runtime.py --serial SERIAL
```

Скрипт скачивает два официальных архива Codex 0.165.0 для ARM64 musl — около 135 МБ суммарно. Размер и SHA-256 сверяются с `tools/runtime.lock.json`. Исполняемые файлы распаковываются на компьютере, затем копируются через авторизованный ADB в `/data/adb/avr-codex`.

PEM-набор стандартных доверенных корней скачивается с [curl CA Extract](https://curl.se/docs/caextract.html) для самого процесса Codex. Системные сертификаты Android не меняются. Можно передать свой **стандартный** PEM-набор корней явно:

```console
python tools/install_runtime.py --serial SERIAL --ca-bundle /path/to/cacert.pem
```

Для предварительного скачивания и проверки без изменений на телефоне:

```console
python tools/install_runtime.py --prepare-only
```

Если runtime уже установлен, скрипт остановится. Для осознанного обновления сначала завершите задачи и остановите помощника в приложении, затем используйте:

```console
python tools/install_runtime.py --serial SERIAL --update
```

`--update` заменяет исполняемые файлы, запускной скрипт и частный CA bundle. Существующие `home/config.toml`, `home/auth.json` и инструкции/файлы workspace сохраняются.

## 4. Запустите клиент

Откройте Codex Mobile, разрешите root именно приложению, затем разрешите уведомления. У root-движка приватные stdin/stdout; открывать сетевой порт или Docker API не требуется.

Меню истории → аккаунт → «Войти через браузер» или «Войти по коду». Авторизация проходит на официальной странице OpenAI. После завершения вернитесь в клиент. Обычные чаты ChatGPT сюда не импортируются.

Если Android отключил уведомления: аккаунт → «Уведомления о задачах» откроет системные настройки приложения. У микрофона собственное разрешение, которое запрашивается при первом использовании.

## Сеть и Docker

В некоторых сетях для подключения к OpenAI нужен VPN или прокси. В шаблоне `runtime/run` предусмотрено использование уже запущенного локального HTTP-прокси Happ `127.0.0.1:10809`. Это обычный loopback-адрес, не готовая подписка. Можно изменить шаблон под собственное окружение; токены и подписки в Git не добавляйте.

Обёртка Docker устанавливается только если уже существует `/data/adb/avr-docker/ctl`. Для другого расположения подготовьте собственную обёртку `bin/docker`. Совместимое ядро и Docker Engine устанавливаются отдельно.

## Частые проблемы

- **«Не удалось запустить: проверь root-доступ»** — проверьте разрешение `su` у `local.avr.codex`, наличие runtime и исполняемых `bin/codex`, `bin/codex-code-mode-host`.
- **Вход или запрос не проходит по сети** — проверьте интернет, часы телефона и настройки VPN/прокси. Закончите или отмените текущий вход перед обновлением APK.
- **Модель отвечает, но команды не выполняются** — проверьте второй бинарный компонент `codex-code-mode-host` и разрешение root.
- **Не работает генерация картинки** — инструмент должен быть доступен текущему аккаунту/модели; возможны ограничения или исчерпание лимита сервиса. Клиент не обходит их.
- **При разрыве связи сообщение осталось в очереди** — проверьте историю перед повторной отправкой. После неоднозначного результата доставки очередь ставится на паузу, чтобы не повторять команды автоматически.
