# Установка личной копии 0.6.6

Эта ветка публикует личную сборку `local.avr.codex.copy` для существующего root-окружения AVR. Подписанный APK из релиза обновляет установленную копию с тем же ключом и сохраняет её данные. Приватный ключ подписи и данные телефона не публикуются.

База этой сборки — `/data/adb/avr-codex-copy`, socket names — `avr.codex.copy.*`. Корневые helper-скрипты пока привязаны к UID 10458 текущей установки. Для другого телефона потребуется адаптация путей и UID. APK не является универсальным установщиком root-окружения и не переносит аккаунты автоматически.

## Существующая копия на телефоне

Дождись завершения задач, затем установи `Codex-Mobile-Copy-0.6.6.apk` поверх `local.avr.codex.copy`. Не удаляй приложение перед обновлением: это удалит локальные настройки и ключи Android Keystore.

## Подготовка исходников

Сборка APK: `python tools/build.py --sdk /path/to/sdk`. Сборка root helpers: `python tools/build_phone_tools.py --sdk /path/to/sdk`. Команды только готовят файлы в `dist/`; телефон не изменяют. Подробности — в BUILD.md.

В `phone-tools/` опубликованы исходники root CLI, временного HTTPS/watchdog/cleanup и фонового дисплея. Runtime launcher копии — `runtime/run-copy`. Устанавливать эти файлы следует только в собственное подготовленное root-окружение после проверки путей; автоматически они не запускаются.

`tools/install_runtime.py` и `runtime/run` оставлены из основного проекта для исходного пакета `/data/adb/avr-codex`. Они не устанавливают личную копию. Исходная инструкция сохранена в UPSTREAM_INSTALL.md.
