# Interface and settings

The drawer footer opens Настройки. Account sign-in lives in its own panel. Подключение groups the execution device, Xray subscriptions/hosts and named SSH servers. Приложение groups phone access and Android notification settings. Система → Обслуживание contains diagnostics and stopping the helper. Each panel has an explicit Close action; Back returns to the parent panel and preserves its scroll position. Live connection errors update the settings root. The temporary HTTPS-use chip remains visible in chats.

Chat surfaces, selectors, status cards and native credential forms share a dark green/neutral palette with mint accents. Model, reasoning, attachment and delivery selectors retain their actions. Secret inputs remain native and secure; no credentials enter the WebView. Xray transport and SSH authentication logic are unchanged.

Local files open a native bottom sheet with name, file type, size and large Send/Open actions. Android’s own Sharesheet still chooses the receiving app and recipient, with a read-only content URI. Browser previews use synthetic accounts and hosts. Native file previews render the test dialog itself into a bitmap; they never capture other apps or phone notifications.
