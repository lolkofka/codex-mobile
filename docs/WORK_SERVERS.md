# Рабочие серверы по названию

Меню аккаунта → «Рабочие серверы» → «Добавить сервер». Доступны название,
домен/IP, порт SSH, логин, закрытый SSH-ключ (вставка или выбор файла),
пароль и отдельный пароль зашифрованного ключа.

Без ключа поле пароля используется для входа по SSH. С ключом это пароль
root для `su`; он не подставляется как пароль SSH и не используется для
расшифровки ключа. По умолчанию команды выполняются под сохранённым логином.
Если логин уже root, повторное повышение прав не требуется. Для `su` из
другого логина необходим ключ SSH и сохранённый пароль root.

Пароли и закрытые ключи хранятся только в AES-GCM-зашифрованном файле
приложения. Ключ AES привязан к UID через Android Keystore. Секретные поля
редактируются нативными защищёнными диалогами и не передаются JavaScript
или в сообщения модели. При пустом поле прежний пароль сохраняется;
переключатель позволяет удалить его. Смена способа входа очищает пароль,
если новый пароль не указан, чтобы не перепутать пароль SSH и root.

Брокер принимает запросы только через Unix-сокет от root и собственного UID;
сетевого порта управления нет. При первом успешном входе запоминается ключ
сервера. Изменение ключа блокирует последующее подключение. На другой адрес
профиль редактируется владельцем.

Примеры для помощника:

```sh
codex-servers list
codex-servers exec 'Тестовый' -- 'cd /srv/project && git status --short'
codex-servers exec 'Тестовый' --root -- 'id -u'
codex-servers put 'Тестовый' /data/local/tmp/report.txt /tmp/report.txt
codex-servers get 'Тестовый' /tmp/report.txt /data/local/tmp/report-copy.txt
```

Команды ограничены 120 секундами по умолчанию; `--timeout` принимает 1–600.
Передача файла ограничена 10 МБ и 120 секундами. `--root` использует `su`
с отключённым эхо терминала: пароль передаётся в stdin после запроса, а не
в командной строке. Управление трафиком телефона не применяется к SSH-паролям.
Закрытие сервиса закрывает его SSH-соединения.

На отдельном SSH-сервере, слушающем только loopback телефона, проверены
парольный вход, ключ, зашифрованный ключ, отдельный пароль root, отсутствие
эха пароля, SFTP, тайм-аут, блокировка изменённого ключа сервера, шифрование
профилей и выполнение через root CLI по русскому названию.
