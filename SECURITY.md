# Безопасность и личные данные

Клиент предназначен для собственного rooted-устройства. Root-движок выполняет команды с полномочиями владельца; профиль `danger-full-access` не является песочницей.

## Что хранится локально

- Android private storage: настройки интерфейса, черновик, очередь, копии вложений и зашифрованный SSH-ключ, если настроен режим ПК.
- `/data/adb/avr-codex/home/`: авторизация, настройки и история самого Codex. Это приватные данные, а не содержимое публичного проекта.
- `cache/shared/`: копии файлов, открытые пользователем в другом Android-приложении через ограниченный URI grant.
- Локальный development/release keystore и пароль сборки: отдельно от публичных исходников.

Запросы модели и выбранные вложения передаются сервису OpenAI через движок, используя авторизацию пользователя. При работе с моделью применяются условия и настройки соответствующего аккаунта. Фото не загружаются внешним хостингом ради предпросмотра.

Локальный HTTP/CONNECT мост требует случайный временный пароль и слушает только `127.0.0.1`; пароль не включён в APK и не сохраняется в настройках. Он не предоставляет root API. HTTPS остаётся зашифрованным между движком и сервером, без установки сертификатов. Выбранный VPN/прокси видит обычные для такого туннеля сетевые метаданные.

## Публикация

В репозиторий и release APK не включены личный runtime, `auth.json`, SSH-профиль, ключи, пользовательские логи, фото, подписки VPN, дампы телефона и ключ подписи. Приватные каталоги исключены `.gitignore`. Публикуемый APK проверяется отдельно от исходников, включая DEX и ресурсы.

Эти меры не заменяют проверку изменений перед каждым будущим релизом. Не прикладывайте к issues приватные каталоги, токены, полные логи входа или дампы памяти.

## Сообщение об уязвимости

Используйте [private vulnerability reporting](https://github.com/lolkofka/codex-mobile/security/advisories/new), если эта возможность включена. Если GitHub не предлагает приватный отчёт, создайте issue только с просьбой о приватном канале, без секрета и без подробностей эксплуатации.
